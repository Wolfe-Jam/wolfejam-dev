Released

  • rust-mcp-preflight v0.2.3 Checks an MCP Registry listing before you publish: the crates.io README line, server.json's publish rules, the server name and its namespace login. Why: the registry checks these when you publish, after the crate is already on crates.io. Preflight checks them first. New: the namespace login check (0.2.0) reads the DNS or HTTP key for a domain namespace the way the registry does. 0.2.3 is back in step with the registry: every published key counts, and a temporary failure fetching the HTTP key is tried once more. cargo install rust-mcp-preflight · post · notes
  • mcp-better v0.6.0 A modern MCP server setup for MCP 2026-07-28, written as a textbook: Rust, rmcp, stdio. Why: a textbook that claims a spec should pass that spec's own tests. New: CI runs the official MCP conformance suite. Cache hints come back on every list and read, and the server declares only what it answers. npx mcp-better · repo
  • mcp-context-card v1.9.6 Makes a project's context (AGENTS.md), memory and identity discoverable to any MCP client, through the Server Card _meta block and ai-catalog.json. New: speaks MCP 2026-07-28 on the SDK v2 (1.8.0). One command, three surfaces: the mini card in an MCP Apps host, Markdown everywhere else (1.9.0). Its AGENTS.md authoring now uses agents-md-facts 0.2.0 (1.9.6). npx mcp-context-card card · repo
  • agents-md-facts v0.2.2 Authors a minimal AGENTS.md from your repo's facts. Never guessed. New: 0.2.0 keeps everything 0.1.0 authored and adds to it, read from what the repo declares. 0.2.2: a Rust repo's title and version come from Cargo.toml. npx agents-md-facts --dry-run · repo
